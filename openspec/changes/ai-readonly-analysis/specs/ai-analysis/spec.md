## Purpose

在终端客户端内提供只读的 AI 分析能力：解释选中日志、归纳会话输出、诊断连接失败，且绝不执行命令或改变远端状态。

## ADDED Requirements

### Requirement: AI 服务配置

系统 SHALL 允许用户配置 OpenAI 兼容服务的 Base URL、模型名与 API Key，并 SHALL 将 API Key 存入加密凭据库。

#### Scenario: 保存配置

- **WHEN** 用户在设置页填写 Base URL、模型名与 API Key 并保存
- **THEN** Base URL 与模型名持久化到设置存储，API Key 写入加密凭据库，明文设置文件中不出现 API Key

#### Scenario: 渲染进程不可读取密钥

- **WHEN** 渲染进程向主进程查询 AI 状态
- **THEN** 只返回是否已配置，不返回 API Key 内容

#### Scenario: 测试连接

- **WHEN** 用户点击「测试连接」
- **THEN** 系统使用当前配置发起一次最小模型请求，并返回成功或可读的失败原因

#### Scenario: 配置不完整

- **WHEN** Base URL、模型名或 API Key 任一缺失
- **THEN** AI 分析入口仍可见，但发起分析时系统不请求模型，提示用户先完成配置

### Requirement: 选中文本解释

系统 SHALL 允许用户对终端中选中的文本发起 AI 解释，并在右侧抽屉中流式展示结果。

#### Scenario: 选区出现入口

- **WHEN** 用户在终端中选中非空文本
- **THEN** 选区附近出现「AI 解释」按钮，取消选中后按钮消失

#### Scenario: 发起解释

- **WHEN** 用户点击「AI 解释」
- **THEN** 系统将选中文本与连接名称发送给已配置的模型，右侧抽屉打开并逐段展示解释、可能原因与排查建议

### Requirement: 会话日志摘要

系统 SHALL 允许用户对当前会话最近的终端输出生成摘要。

#### Scenario: 生成摘要

- **WHEN** 用户在已连接会话中点击「AI 摘要」
- **THEN** 系统取该会话最近 300 行输出发送给模型，并在右侧抽屉展示异常归纳、时间线索与建议的下一步

#### Scenario: 会话不可用

- **WHEN** 会话不存在或已关闭时发起摘要
- **THEN** 系统不请求模型，并提示会话不可用

### Requirement: 连接失败诊断

系统 SHALL 允许用户针对连接失败发起 AI 诊断，且发送内容不包含密码、私钥或口令。

#### Scenario: 发起诊断

- **WHEN** 会话处于错误状态时用户点击「AI 诊断」
- **THEN** 系统将错误信息、主机、端口、用户名与认证方式发送给模型，并在右侧抽屉展示可能原因与检查清单

#### Scenario: 不发送凭据

- **WHEN** 系统构造诊断请求
- **THEN** 请求内容不包含密码、私钥内容、私钥口令或 API Key

### Requirement: 只读安全约束

AI 分析功能 SHALL NOT 执行命令、向终端写入数据或调用任何 MCP 工具。

#### Scenario: 模型建议不自动执行

- **WHEN** 模型输出中包含命令或可执行步骤
- **THEN** 系统仅展示文本，不写入终端、不自动执行，需用户自行决定后续操作

### Requirement: 流式输出与取消

系统 SHALL 以流式方式展示模型输出，并允许用户中途停止。

#### Scenario: 中途停止

- **WHEN** 用户在生成过程中点击「停止」
- **THEN** 系统终止本次请求并保留已接收的部分内容

#### Scenario: 请求失败

- **WHEN** 模型服务返回 HTTP 错误、超时或无法解析响应
- **THEN** 系统在抽屉中展示可读错误信息，并保留已接收的部分内容

#### Scenario: 多次请求

- **WHEN** 用户在一个请求进行中发起新的分析
- **THEN** 系统终止旧请求，只展示新请求的结果

### Requirement: 结果展示与复制

系统 SHALL 在右侧抽屉中保留最近一次分析结果，并允许复制。

#### Scenario: 复制结果

- **WHEN** 用户点击「复制」
- **THEN** 当前抽屉中的完整结果文本写入系统剪贴板

#### Scenario: 不同会话之间切换

- **WHEN** 用户切换到其他会话标签
- **THEN** 抽屉保持打开并保留上次结果，不自动发起新请求
